# CLAUDE.md

В этом репозитории два проекта: одностраничный сайт NOVA (корень: `index.html`,
`script.js`, `style.css`) и торговый бот Bybit в папке `hype-bot/`.

Работая над ботом, сначала прочитай `hype-bot/docs/STATUS.md` — там текущий этап,
решения пользователя, правила работы (остановка после этапа, цифры только из
выполненного кода, отложенные данные не трогать) и следующий шаг.

Тесты бота: `cd hype-bot && python -m pytest`.
