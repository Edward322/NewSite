# CLAUDE.md

В этом репозитории два проекта: одностраничный сайт NOVA (корень: `index.html`,
`script.js`, `style.css`) и торговый бот Bybit в папке `hype-bot/`.

Работая над ботом, сначала прочитай `hype-bot/docs/STATUS.md`: там текущий этап, параметры
и решения пользователя, правила работы и раздел «Как продолжить в новой сессии». Правила:
- цифры только из выполненного кода;
- ограничители не ослаблять;
- реальные деньги — только после явного «да» пользователя.

Тесты бота: `cd hype-bot && python -m pytest`.
