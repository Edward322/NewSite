# NOVA — одностраничный сайт со слайдами

Простой сайт на чистых HTML, CSS и JavaScript: без сборки, фреймворков и зависимостей.
Каждый раздел — полноэкранный слайд со своим фоном, анимациями и переходом.

## Как открыть

Откройте `index.html` в браузере. Можно и через любой локальный сервер:

```bash
npx serve .
```

Для публикации подойдёт GitHub Pages или любой статический хостинг: достаточно загрузить три файла.

## Что внутри

| Файл         | Назначение                                       |
|--------------|--------------------------------------------------|
| `index.html` | Разметка и тексты всех слайдов                   |
| `style.css`  | Оформление, фоны слайдов, анимации, адаптив      |
| `script.js`  | Движок слайдов, переходы и интерактивные эффекты |

### Слайды

1. **Главная** — частицы, реагирующие на мышь, парящие сферы с параллаксом, побуквенное появление заголовка.
2. **О нас** — светлый слайд: слова манифеста проявляются по очереди, внизу бегущая строка.
3. **Услуги** — стеклянные карточки с 3D-наклоном и бликом за курсором.
4. **Цифры** — ретро-сетка и солнце, счётчики и заполняющиеся кольца.
5. **Работы** — 3D-карусель проектов: тянется мышью или пальцем и крутится сама.
6. **Контакты** — переливающийся фон, магнитная кнопка с вращающимся текстом.

### Переходы между слайдами

- `liquid` — «жидкая» шторка с изогнутым краем;
- `circle` — круг, раскрывающийся от курсора;
- `diagonal` — диагональная шторка.

Переход задаётся атрибутом `data-transition` у слайда, на который вы переходите.

### Общие эффекты

Прелоадер, свой курсор, магнитные кнопки, зерно поверх страницы, счётчик и прогресс слайдов,
точки навигации, шапка, которая перекрашивается на светлом слайде.

## Управление

- колесо мыши или тачпад — один жест листает один слайд;
- свайп вверх или вниз на телефоне;
- `↑` `↓`, `PageUp` `PageDown`, `Пробел`, `Home` `End`, цифры `1`–`6`;
- `←` `→` вращают карусель на слайде «Работы»;
- точки справа, пункты меню и стрелки внизу.

Адрес страницы меняется при листании (`#about`, `#work`…), так что можно отправить ссылку на нужный слайд.

## Как изменить под себя

- **Тексты** — прямо в `index.html`.
- **Цвета** — переменные в начале `style.css` (`--violet`, `--pink`, `--cyan`, `--orange`, `--mint`).
- **Новый слайд** — скопируйте любой `<section class="slide">`, задайте ему `id`, `data-title`
  и `data-transition`. Точки навигации и счётчик подстроятся сами.
- **Светлый слайд** — добавьте `data-theme="light"`, чтобы шапка и счётчик стали тёмными.
- **Анимация текста** — атрибут `data-split="chars"` (по буквам), `"words"` (по словам)
  или `"highlight"` (слова проявляются по очереди).
- **Почта и соцсети** — замените `hello@example.com` и ссылки `#` в слайде «Контакты».

## Доступность

- При включённой в системе настройке «уменьшить движение» анимации отключаются,
  а слайды сменяются простым затуханием.
- Без JavaScript сайт показывается как обычная страница с прокруткой.
- Текст, разбитый на буквы для анимации, скринридеры читают целиком.
