# Торговый бот Bybit: пробой канала 4h на корзине монет

Бот сам торгует бессрочными USDT-контрактами Bybit круглосуточно на вашем компьютере
с Windows. Сейчас он работает **на демо-счёте**. Демо — это проверка на новых данных.

## Честно о результатах

- Стратегию выбрали после просмотра истории. На отложенных данных она **не прошла**
  критерии (`reports/STAGE3C_HOLDOUT.md`).
- На всей истории с вашими ограничителями (данные уже не чистые, `reports/STAGE1_RISK.md`):
  - 25 USDT → 30,34 за 3,25 года, максимальная просадка 37 %;
  - 70 % времени бот провёл в режиме половинного риска и торговал мало.
- Прибыль не обещается. Демо проверяет, что движок работает правильно и нет явного провала.
  Прибыльность за несколько недель оно не докажет.

## Что нужно от вас

**Заранее, один раз:**
1. Компьютер с Windows 10/11, включённый круглосуточно. Сон отключит установщик.
   Если отключат свет: включите в BIOS «Restore on AC Power Loss → Power On» (необязательно,
   но без этого после отключения света компьютер придётся включить вручную).
2. Аккаунт на bybit.com и **ключ API демо-счёта** (шаг 3).
3. Telegram — по желанию (шаг 4): сообщения о сделках, ошибках, ежедневное «жив»,
   недельный отчёт, команды `/status` и `/stop`.
4. Один раз запустить `install.bat` (шаг 5) и прислать результат самопроверки (шаг 6).

**Во время демо:**
- Не торгуйте вручную на демо-счёте: бот примет чужие позиции за расхождение и перестанет
  открывать новые.
- Через неделю или позже запустите `windows\demo_report.bat` и пришлите файл
  `reports\DEMO_REPORT.md`.

## Установка

### Шаг 1. Скачать программу
1. Скачайте архив:
   https://github.com/Edward322/NewSite/archive/refs/heads/claude/nice-allen-xl48t9.zip
2. Распакуйте в папку **без русских букв и пробелов**, например `C:\hype`.
   Папка бота: `C:\hype\NewSite-claude-nice-allen-xl48t9\hype-bot`.

### Шаг 2. Python
Установщик сам попробует поставить Python 3.12. Если не получится, поставьте вручную:
1. https://www.python.org/downloads/ → «Windows installer (64-bit)».
2. В первом окне установщика отметьте **«Add python.exe to PATH»**.

### Шаг 3. Ключ API демо-счёта
1. Войдите на bybit.com и переключитесь в **Демо-торговлю** (Demo Trading) — переключатель
   в меню аккаунта.
2. Наведите на значок профиля → **API** → **Создать новый ключ** → **Системный**.
3. Права:
   - чтение и запись;
   - **Контракты: Ордера, Позиции**;
   - **Единый торговый аккаунт: Торговля**.
   - **Вывод средств и переводы НЕ отмечать.** Самопроверка остановит бота, если у ключа
     есть право вывода.
4. Сохраните API Key и Secret: установщик их спросит. Secret Bybit показывает **только один
   раз**, при создании ключа. Они записываются только в файл `.env` в папке бота и никуда
   не отправляются.
5. В окне установщика вставляйте **правой кнопкой мыши**: Ctrl+V в скрытом поле секрета
   может вставить не текст. Установщик сразу проверяет ключ на бирже и при ошибке
   объясняет, что не так, и просит ввести заново.

### Шаг 4. Telegram (по желанию)
Установщик спросит токен. Чтобы его получить:
1. В Telegram найдите **@BotFather** и отправьте `/newbot`.
2. Придумайте имя бота и скопируйте токен.
3. Когда установщик попросит, отправьте своему боту любое сообщение — так бот узнает ваш
   чат. Команды принимаются только из него.

### Шаг 5. Установка
Дважды щёлкните `hype-bot\windows\install.bat` и согласитесь на права администратора
(они нужны для автозапуска). Установщик:
- создаст окружение Python и поставит библиотеки;
- спросит ключи и Telegram;
- проверит связь с Bybit **без ордеров**;
- добавит бота в планировщик Windows: запуск при включении компьютера (даже без входа
  в систему), перезапуск при сбое;
- отключит сон при питании от сети;
- запустит бота.

Если Windows покажет «Система Windows защитила ваш компьютер», нажмите «Подробнее» →
«Выполнить в любом случае».

### Шаг 6. Самопроверка на настоящей бирже
Запустите `windows\selfcheck.bat`. Скрипт проверяет:
- ключи и их права;
- часы, инструменты, спреды, комиссии;
- загрузку данных и WebSocket;
- на демо — один пробный минимальный ордер (около 5 виртуальных USDT) со стопом, который
  сразу закрывается;
- «сухой» прогон движка на реальных данных без ордеров.

Откроется папка с файлом `selfcheck_demo_….txt` — **пришлите его**. Секретов в нём нет.

## Управление

| Что | Как |
|---|---|
| Состояние | `windows\status.bat` или `/status` в Telegram |
| **Аварийная остановка**: закрыть позиции, отменить ордера, выключить бота | `windows\stop_bot.bat` или `/stop` в Telegram |
| Запустить снова после остановки | `windows\resume.bat` |
| Ввести ключи заново (с проверкой на бирже) | `windows\keys.bat` |
| Отчёт по демо | `windows\demo_report.bat` → `reports\DEMO_REPORT.md` |
| Обновить программу (ключи, настройки и данные сохраняются) | `windows\update.bat` |
| Убрать из автозапуска | `windows\uninstall.bat` |
| Журнал | `logs\bot_demo.log` |

**Что бот делает сам:**
- скачивает свежие данные с Bybit;
- торгует раз в 4 часа (00, 04, 08, 12, 16, 20 UTC);
- сверяется с биржей при старте и каждую минуту;
- после выключения компьютера или интернета при старте сверяется с биржей. Всё это время
  позиции защищены **стопами на бирже**.

## Что делает стратегия и какие ограничители

- **Сигнал:** закрытие свечи 4h выше максимума (ниже минимума) предыдущих 38 свечей —
  вход в лонг (шорт).
- **Выходы:**
  - стоп 2,5 ATR ставится на бирже вместе со входом, одним запросом;
  - стоп подтягивается на 4 ATR от экстремума;
  - выход по обратному пробою канала 19 свечей.
- **Корзина:** 15 монет. Новые входы — только по монетам с достаточной ликвидностью
  (правило — `docs/RISK_PROTOCOL.md`).
- **Ограничители:**
  - риск 2 % капитала на сделку;
  - открытый риск всех позиций ≤ 6 %, с учётом корреляции монет ≤ 4 %;
  - не больше 4 позиций;
  - дневной лимит убытка 6 %;
  - просадка 20 % от пика → риск вдвое, 40 % → все позиции закрываются и бот
    останавливается до ручного запуска;
  - изолированная маржа, плечо такое, чтобы ликвидация была минимум вдвое дальше стопа.
- **Капитал бота — 25 USDT.** На демо-счёте с большим виртуальным балансом бот считает
  своими только 25 USDT плюс свой результат.

## Реальные деньги — только после вашего «да»

Правила — `docs/LIVE_PROTOCOL.md`. Когда решите:
1. Узнайте свой внешний IP (например, на 2ip.ru); он у вас статический.
2. На bybit.com создайте **субаккаунт** и переведите на него ровно 25 USDT. Ключ создайте
   в субаккаунте: профиль → API → **Создать новый ключ** → **Системный**:
   - чтение и запись;
   - **Контракты: Ордера, Позиции**, **Единый торговый аккаунт: Торговля** — и больше ничего;
   - **вывод средств, переводы, биржа (Exchange) — НЕ отмечать**;
   - **«Разрешить доступ только с доверенных IP»** — впишите свой IP. Без привязки
     самопроверка не пропустит ключ.
3. Сообщите разработчику. Он проверит отчёт по демо и включит флаг `live.enabled: true`.
   Без этого флага реальный режим не запускается.
4. Запустите `windows\install.bat live` (спросит ключи реального счёта) и
   `windows\selfcheck.bat live`. На реальном счёте пробный ордер не выставляется.
5. Остановите демо-бота: `windows\stop_bot.bat demo`, затем `windows\uninstall.bat demo`.

На реальном счёте действуют те же ограничители. Если исполнение (проскальзывание, стопы)
заметно хуже, чем было на демо, бот сам перестаёт открывать новые позиции и пишет
в Telegram.

## Безопасность
- Ключи — только в `.env` на вашем компьютере. Этот файл не попадает в git.
- Ключ без права вывода, реальный — с привязкой к IP.
- Второй экземпляр бота не запустится. Каждый ордер имеет уникальный идентификатор, поэтому
  двойной вход после сбоя невозможен.

## Для разработчика
- Состояние и порядок работы: `docs/STATUS.md`.
- Тесты: `cd hype-bot && python -m pytest`. Движок проверяется на имитаторе биржи
  `bot/exchange/sim.py` и совпадает с бэктестом сделка в сделку.
- Код:
  - `bot/engine/` — движок, сверка, Telegram, отчёты;
  - `bot/exchange/` — клиент Bybit V5 и имитатор;
  - `bot/risk/` — риск, общий с бэктестом;
  - `bot/report/` — исполнение, сравнение, отчёт по демо;
  - `bot/backtest/`, `bot/strategy/`.
