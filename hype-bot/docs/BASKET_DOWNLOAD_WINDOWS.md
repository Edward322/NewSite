# Как скачать данные корзины монет (Windows)

Нужно для варианта 3 — торговли корзиной монет. Как и в первый раз, ключи API
не нужны: скачиваются только общедоступные рыночные данные.

Что скачивается для каждой монеты корзины (с 2023 года или с листинга):
свечи 15m, ставки финансирования, премиальный индекс (базис), открытый интерес,
соотношение лонгов и шортов; плюс BTC и ETH как рыночные ориентиры и индекс
страха и жадности. Состав корзины выбирается автоматически по правилу из
конфига (ликвидность, история, минимальный ордер по силам депозиту 10 USDT).

## Шаги

1. Скачайте свежую версию программы (ссылка та же, код обновился):
   https://github.com/Edward322/NewSite/archive/refs/heads/claude/wonderful-ramanujan-6lakcx.zip
2. Распакуйте в **новую** папку, например `C:\hype2`.
3. Дважды щёлкните
   `C:\hype2\NewSite-claude-wonderful-ramanujan-6lakcx\hype-bot\windows\download_basket.bat`.
   Если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
4. Ждите 30–60 минут. Если оборвётся — запустите файл ещё раз, продолжит с места остановки.
5. В конце откроется папка `upload` с файлом `basket-data.zip`.
6. Откройте https://github.com/Edward322/NewSite/releases/new, в «Choose a tag»
   впишите `data-v2` → «Create new tag», в «Release title» — `data-v2`,
   перетащите `basket-data.zip`, дождитесь загрузки, нажмите «Publish release».
7. Напишите «загрузил».
