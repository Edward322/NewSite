# Как скачать историю с Bybit на своём компьютере (Windows)

Зачем это нужно: серверы, на которых идёт разработка, находятся в стране,
для которой Bybit закрыл доступ к API. Поэтому историю цен скачиваете вы,
а исследование стратегий идёт на этих файлах. Всё делается один раз.

Ключи API для этого шага не нужны — скачиваются только общедоступные
рыночные данные.

## Шаг 1. Установить Python

1. Откройте https://www.python.org/downloads/ и скачайте Python 3.13
   («Windows installer (64-bit)»).
2. Запустите установщик. **Внизу первого окна поставьте галочку
   «Add python.exe to PATH»**, затем нажмите «Install Now».

Если Python 3.12 или 3.13 уже установлен, этот шаг можно пропустить.

## Шаг 2. Скачать программу

1. Скачайте архив по ссылке:
   https://github.com/Edward322/NewSite/archive/refs/heads/claude/wonderful-ramanujan-6lakcx.zip
2. Распакуйте его в папку без русских букв и пробелов в пути, например `C:\hype`.

## Шаг 3. Запустить загрузку

1. Откройте папку
   `C:\hype\NewSite-claude-wonderful-ramanujan-6lakcx\hype-bot\windows`.
2. Дважды щёлкните файл `download_data.bat`.
3. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите
   «Подробнее» → «Выполнить в любом случае».
4. Ждите. Первый запуск ставит библиотеки (несколько минут), затем идёт
   загрузка — около 30–60 минут. В окне видно, до какой даты дошла загрузка.
5. Если загрузка оборвалась (интернет, сон компьютера) — просто запустите
   `download_data.bat` ещё раз: он продолжит с места остановки.

В конце откроется папка `upload` с файлом `hype-data.zip`.

## Шаг 4. Отправить файл

1. Откройте https://github.com/Edward322/NewSite/releases/new
   (нужно войти в свой аккаунт GitHub).
2. Нажмите «Choose a tag», впишите `data-v1` и выберите
   «Create new tag: data-v1 on publish».
3. В поле «Release title» впишите `data-v1`.
4. Перетащите `hype-data.zip` в область «Attach binaries by dropping them here»
   и дождитесь окончания загрузки файла.
5. Нажмите «Publish release».

Репозиторий публичный, поэтому архив будет виден всем. В нём только
общедоступные рыночные данные Bybit — никаких ключей и данных аккаунта.

## Если что-то пошло не так

Сделайте снимок экрана окна с ошибкой и пришлите его. Подробный журнал
лежит в файле `hype-bot\logs\bot.log`.
