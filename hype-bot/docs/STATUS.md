## План исследования корзины (пользователь просил «все потенциально прибыльные варианты»)

1. Портфельный бэктестер: общий капитал, несколько позиций, лимит суммарного риска,
   ограничители на уровне счёта, база 15m. **Тест: на одной монете совпадает со старым
   движком сделка в сделку.**
2. Кандидаты (зафиксированы заранее): импульс по монете (4h/1d, с поправкой на волатильность;
   лонг-шорт и только лонг); трендовый пробой 4h/1d; межмонетный импульс; межмонетный
   базис/финансирование против перегретых; OI + цена; против толпы по лонг/шорт;
   фильтры режима — тренд BTC, индекс страха и жадности. Отклонены заранее: часовая
   сезонность, опережение BTC.
3. Walk-forward (~12 мес подбор / 3 мес проверка), подбор по плато, учёт числа попыток,
   «дефлированный» Sharpe для финалиста; сравнение с buy & hold корзины равными долями.
4. Финалист → одна проверка на отложенных данных → устойчивость (соседи, ×2 издержки,
   Монте-Карло) → отчёт с графиками (палитра dataviz) → ждать решения пользователя.
