## Карта кода

- `bot/data/` — загрузка (`downloader.py`, `basket.py`), хранилище, качество, перенос архивом, `split.py` (holdout).
- `bot/risk/` — `sizing.py` (объём, плечо, ликвидация), `guards.py` (лимиты).
- `bot/backtest/` — `engine.py` (одна монета), `portfolio.py` (корзина, общий капитал), `metrics.py`, `causality.py`, `audit.py`.
- `bot/data/panel.py` — данные корзины на общей 15m-сетке, загрузка dev/holdout.
- `bot/strategy/` — `base.py` (интерфейс), `indicators.py`, `candidates.py` (7 семейств, одна монета), `basket.py` (6 семейств корзины).
- `research/` — скрипты исследований, `wf.py` (walk-forward); выводы в `reports/`.
